⚙️ For Grown-ups

📱 Books are saved on this phone. Each phone keeps its own library — use Export / Import JSON below to share or back up a library between phones.

📲 Put it on your iPhone Home Screen

  1. Open this page in Safari on the iPhone.
  2. Tap the Share button (square with an arrow).
  3. Tap “Add to Home Screen”, then Add.
  4. Open “Monroe's Library” from the Home Screen — it works like an app, camera included (allow camera access when asked).

Sharing with family: this same page can live on GitHub Pages — push this single index.html to a public repo (e.g. t3riah/monroes-library), turn on Settings → Pages → Deploy from branch (main / root), and send everyone the link t3riah.github.io/monroes-library/. Replacing the file in the repo updates it for everyone; each phone's books stay on that phone.
